# Popover

<Description>トリガー要素に紐づくフローティングパネル。</Description>

## Installation

<CodeBlock
  code={`npx shadcn@latest add https://kasumi-ui.vercel.app/r/popover`}
/>

## Usage

<ComponentPreview>
  <Popover>
    <PopoverTrigger asChild>
      <Button variant="outline">開く</Button>
    </PopoverTrigger>
    <PopoverContent>
      <div className="space-y-2">
        <p className="text-sm font-semibold">表示設定</p>
        <p className="text-sm text-muted-foreground">
          お好みの表示オプションを設定できます。
        </p>
      </div>
    </PopoverContent>
  </Popover>
</ComponentPreview>

<CodeBlock code={`import {
