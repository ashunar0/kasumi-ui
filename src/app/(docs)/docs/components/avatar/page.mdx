import { Avatar, AvatarImage, AvatarFallback } from "@/components/ui/avatar";

export const avatarProps = [
  {

  },

# Avatar

<Description>ユーザーのプロフィール画像やイニシャルを表示するアバターコンポーネント。</Description>

## Usage

<ComponentPreview>
  <Avatar>
    <AvatarImage src="https://github.com/shadcn.png" alt="ユーザー" />
  </Avatar>
</ComponentPreview>

<CodeBlock code={`import { Avatar, AvatarImage, AvatarFallback } from "@/components/ui/avatar";

<Avatar>
  <AvatarImage src="https://github.com/shadcn.png" alt="ユーザー" />
</Avatar>`} />

## Fallback

画像がない場合はデフォルトのユーザーアイコンが表示されます。AvatarFallback でイニシャル等を指定することもできます。

<ComponentPreview className="gap-4 items-center">
  <Avatar />
  <Avatar>
    <AvatarFallback>AK</AvatarFallback>
  </Avatar>
</ComponentPreview>

<CodeBlock
  code={`{/* デフォルトアイコン */}
<Avatar />

{/* イニシャル */}
<Avatar>
  <AvatarFallback>AK</AvatarFallback>
</Avatar>`}
/>
