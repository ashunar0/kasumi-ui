# Table

<Description>
  データを行と列で表示するためのテーブルコンポーネント。
</Description>

## Installation

<CodeBlock
  code={`npx shadcn@latest add https://kasumi-ui.vercel.app/r/table.json`}
/>

## Usage

<ComponentPreview>
  <Table>
    <TableHeader>
      <TableRow>

        <TableHead>メール</TableHead>
        <TableHead>ステータス</TableHead>
      </TableRow>
    </TableHeader>
    <TableBody>
