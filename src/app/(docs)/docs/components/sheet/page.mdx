# Sheet

<Description>画面端からスライドインするパネル。ナビゲーションや補足情報の表示に使用。Dialog と同じ Radix UI プリミティブをベースに構築。</Description>

## Side

`side` prop で表示位置を指定できます。`top`、`right`、`bottom`、`left` の4方向に対応。
