# Pagination

<Description>ページ番号型のページネーションコンポーネント。前後ナビゲーション、省略記号に対応。</Description>

## Usage

<ComponentPreview>
  <Pagination>
    <PaginationContent>
      <PaginationItem>
        <PaginationPrevious />
      </PaginationItem>
      <PaginationItem>
        <PaginationLink>1</PaginationLink>
      </PaginationItem>
      <PaginationItem>
        <PaginationLink isActive>2</PaginationLink>
      </PaginationItem>
      <PaginationItem>
        <PaginationLink>3</PaginationLink>
      </PaginationItem>
      <PaginationItem>
        <PaginationNext />
      </PaginationItem>
    </PaginationContent>
  </Pagination>
</ComponentPreview>

<CodeBlock code={`import {

## Ellipsis

ページ数が多い場合、省略記号で中間ページを省略できます。

<ComponentPreview>
  <Pagination>
    <PaginationContent>
      <PaginationItem>
        <PaginationPrevious />
      </PaginationItem>
      <PaginationItem>
        <PaginationLink>1</PaginationLink>
      </PaginationItem>
      <PaginationItem>
        <PaginationEllipsis />
      </PaginationItem>
      <PaginationItem>
        <PaginationLink>4</PaginationLink>
      </PaginationItem>
      <PaginationItem>
        <PaginationLink isActive>5</PaginationLink>
      </PaginationItem>
      <PaginationItem>
        <PaginationLink>6</PaginationLink>

      <PaginationItem>
        <PaginationEllipsis />

</ComponentPreview>
