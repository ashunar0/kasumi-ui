# Notion風デモページ設計

## 目的

ウォームグレー + base 16px のデザイントークンが、実際のアプリっぽいUIでどう見えるか確認するデモページ。

## 設計判断

- **1ファイルの静的ページ** (`/demo/page.tsx`) — 再利用コンポーネントは作らない（YAGNI）
- サイドバー + メインコンテンツの2カラムレイアウト
- 既存コンポーネント（Button, Input, Card, ThemeToggle）を自然に組み込む
- ダークモード切り替え対応

## レイアウト

- サイドバー: `w-60` 固定、`bg-secondary`、`text-ui` (14px)
- メイン: 残り幅、`max-w-3xl` で読みやすい幅に制限
- 全体: `h-screen` で画面いっぱい、overflow管理

## サイドバーの中身（全てダミー）

- ワークスペース名 + アイコン
- ページリスト（議事録、設計書、TODO等）
- 選択状態のハイライト
- 下部に設定リンク

## メインコンテンツ

タイポグラフィの全段を自然に使うNotionライクなドキュメント:

- ページタイトル: text-h2
- セクション見出し: text-h3, text-h4
- 本文: text-body (16px)
- メタ情報: text-ui (14px) + muted-foreground
- 既存コンポーネント: Button, Input, Card を自然に配置
- リスト、引用、区切り線、テーブル等のドキュメント要素
