# フォーム要素の設計判断

## 決定事項

### 1. 角丸：ミックス方式

要素の**役割**によって角丸を使い分ける。

| 要素タイプ | 角丸 | 根拠 |
|-----------|------|------|
| ボタン（全 variant） | 10px | アクション要素。丸みが「押せそう」というアフォーダンスを与える |
| Input / Select | 6px | コンテナ要素。シャープな枠が「書き込む場所」という認知を作る |
| Card | 10px | コンテンツの枠。大きい要素なので丸めても崩れない |

sm サイズのボタンは 6px に縮小（小さい要素に大きな角丸は不釣り合い）。

**shadcn/ui との差別化ポイント**: shadcn は全要素同一 radius（8px）。my-ui は役割ベースで分ける。

**根拠**:
- 日本語の字形（ひらがなの曲線）はラウンドなボタンと調和する
- 一方で Input/Select は「記入欄」として認知されるため、シャープな方が紙のメタファーに近い
- カタログでの目視比較で、横並びにしても違和感がないことを確認済み

### 2. Input のスタイル：variant で囲み型と下線型を提供

| variant | 説明 | 用途 |
|---------|------|------|
| `outline` | 囲み型（四辺ボーダー） | 汎用。英語圏のフォームに馴染む |
| `underline` | 下線型（底辺のみ） | 日本語フォームに最適。圧迫感が少なく余白が活きる |

**発見**: 下線型 + lg (44px) の組み合わせが特に良い。44px の余白が下線型だと「贅沢な間」になり、日本語の字面の重さをうまく受け止める。囲み型では「ちょっと大きい」に見える余白が、下線型では「ちょうどいい余裕」に変わる。

**日本語 UI で下線型が多い背景**:
- 日本の書類文化（履歴書、申込書）が下線で記入欄を示す
- 漢字・ひらがなは字面が大きく視覚的密度が高いため、四方を囲むと圧迫感が出る
- 下線だけだと上と左右が開放的で軽やかな印象になる

### 3. my-ui のデザインアイデンティティ

> **「日本語のための UI」** — 下線型フォーム + 丸みのあるアクション + ゆとりのある余白
