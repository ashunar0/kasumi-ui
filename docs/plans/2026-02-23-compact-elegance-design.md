# Compact Elegance デザインシステム

## コンセプト

「小さめ文字 × ゆとり余白」のコントラストで洗練さを出す。ミニマルだけど個性がある、センスのいいデザイン。

## 背景

- shadcn/uiベースのモノトーンでは個性がなさすぎた
- 日本語UIは「大きめ・ゆったり」に振りがちだが、逆の「コンパクトだけど洗練」を目指す
- Figmaの「文字が気持ち小さめでおしゃれ」な感覚を日本語で実現する
- 参考: PayPay Style Guide、Ubie Vitals

## タイポグラフィ

### スケール: Minor Third (×1.2)、base 14px

ベースを16px→14pxに変更。14pxは日本語の可読性を維持できる下限付近だが、GitHub・Figma・Linearと同等であり問題ない。

| 用途 | サイズ | line-height | 算出 |
|------|--------|-------------|------|
| UI文 | 12px | 1.6 | スケール外、最小可読 |
| 本文 | 14px | 1.8 | base |
| H4 | 17px | デフォルト | base × 1.2¹ |
| H3 | 20px | デフォルト | base × 1.2² |
| H2 | 24px | デフォルト | base × 1.2³ |
| H1 | 29px | デフォルト | base × 1.2⁴ |

### 行間の根拠

- **本文 1.8**: JLREQ推奨(1.5〜2.0)の中間。Ubie Vitalsの1.7より少し広く、前バージョンの2.25よりコンパクト。「コンパクトだけど窮屈じゃない」の塩梅。
- **UI文 1.6**: 情報密度とのバランス。通知やラベルなど短文向け。

## スペーシング: Airy

文字が小さい分、コンポーネント間の余白で「ゆとり」を演出する。

## カラーテーマ

2テーマを切り替え可能にする。ベースのグレー（zinc系）は共通。

### テーマ1: 山吹

- accent: `#FFCC00`
- accent上の文字: 黒 (`#18181b`)、**bold**
- 特徴: ポップで個性的。黒×黄色の力強いコントラスト

### テーマ2: ティール × オレンジ

- accent: `#14b8a6` (teal)
- secondary: `#e8590c` (orange)
- accent上の文字: 白、**semibold (600)**
- 特徴: 補色コントラスト。知的さと暖かさの共存
