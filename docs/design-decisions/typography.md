# タイポグラフィ設計

## 方針

フォントサイズと行間に**数学的根拠**を持たせる。「なんとなく」ではなく「なぜこの値か」を説明できる設計。

## フォントサイズスケール: Minor Third (×1.2)

**Modular Scale** を採用。基準サイズ（base）に一定の比率を掛けて段階を作る手法。

- **比率**: 1.2（Minor Third）
- **base**: 16px（ブラウザデフォルト、WCAG推奨ベースライン）

```
base × 1.2⁰ = 16px  (本文)
base × 1.2¹ = 19px  (H4)
base × 1.2² = 23px  (H3)
base × 1.2³ = 28px  (H2)
base × 1.2⁴ = 33px  (H1)
```

### なぜ 16px ベースか

my-uiは特定アプリ専用ではなく**汎用デザインシステム**。テキスト中心のアプリからインタラクション重視のアプリまで幅広く使う前提のため、最も安全なベースラインを選択した。

- 16pxはブラウザデフォルト、Notion等の主要アプリと同等
- WCAGで推奨されるベースライン
- 日本語は画数が多く、英語と同じサイズでも視覚的に密度が高い。16pxなら日本語でも十分な可読性

### text-ui (14px) の位置付け

コンパクトなアプリUI（ダッシュボード、フォーム、テーブル等）では14pxが好ましい場面がある。これを `text-ui` として提供し、用途で使い分ける:

- `text-body` (16px) — 「読む」テキスト。初見ユーザーが読む文章、説明文
- `text-ui` (14px) — 「操作する」テキスト。アプリUI、ラベル、テーブルセル

メルカリも14px/16px/18px/20pxのスケールを使っており、14pxをUI文に使う手法は実績がある。

### なぜ Minor Third (1.2) か

他の候補との比較で決定：

| 比率 | 名前 | 特徴 | 不採用理由 |
|------|------|------|-----------|
| 1.125 | Major Second | ステップが細かい | メリハリが弱い |
| **1.2** | **Minor Third** | **バランスが良い** | **— 採用** |
| 1.25 | Major Third | ダイナミック | 日本語UIでH1が大きすぎる |
| 1.333 | Perfect Fourth | ジャンプが大きい | 段階が足りない |
| 1.618 | 黄金比 | 段階が極端 | UIには不向き |

H1(33px)が大きく感じる場合もあるが、全段を使う必要はない。アプリUIではH3〜H4が中心で、H1はLP等の特別な場面用。

## 行間（line-height）

### 本文: ×1.8

- 日本語はデフォルトの行間（約×1.5）では窮屈に見える
- W3C「日本語組版処理の要件（JLREQ）」では本文の行間に **0.5〜1.0字分** を推奨（= line-height 1.5〜2.0）
- JLREQ推奨範囲内で実際の表示を確認して **×1.8** に決定
- 16pxベースで日本語の可読性を確保

### UI文: ×1.6

- 本文ほどのゆとりは不要だが、デフォルト（×1.5）よりは広く
- UIテキスト（通知、説明文等）は情報密度とのバランスを取る

### 見出し・ボタン: デフォルト

行間の調整は不要。見出しは1〜2行で折り返すことが少なく、ボタンは単行。

## スケール一覧

| 用途 | クラス | サイズ | line-height | 根拠 |
|------|--------|--------|-------------|------|
| UI文 | `text-ui` | 14px | ×1.6 | コンパクトUI用 |
| 本文 | `text-body` | 16px | ×1.8 | base, JLREQ + 実測調整 |
| H4 | `text-h4` | 19px | デフォルト | base × 1.2¹ |
| H3 | `text-h3` | 23px | デフォルト | base × 1.2² |
| H2 | `text-h2` | 28px | デフォルト | base × 1.2³ |
| H1 | `text-h1` | 33px | デフォルト | base × 1.2⁴ |

## 実装

`globals.css` の `@theme inline` 内で Tailwind CSS 4 のカスタムトークンとして定義:

```css
/* Typography Scale: Minor Third (1.2), base 16px */
--text-ui: 0.875rem;              /* 14px */
--text-ui--line-height: 1.6;
--text-body: 1rem;                /* 16px */
--text-body--line-height: 1.8;
--text-h4: 1.1875rem;             /* 19px */
--text-h3: 1.4375rem;             /* 23px */
--text-h2: 1.75rem;               /* 28px */
--text-h1: 2.0625rem;             /* 33px */
```

`text-h1`, `text-body` 等のユーティリティクラスが自動生成され、インラインスタイル不要で使える。
