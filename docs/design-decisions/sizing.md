# フォーム要素のサイズ体系

## 決定事項

フォーム系コンポーネント（Button, Input, Select）に共通の 3 段階サイズを採用する。

| size | 高さ | Tailwind | 角丸 | 用途 |
|------|------|----------|------|------|
| sm | 36px | `h-9` | `rounded-md` | テーブル内、カード内の小さいボタン |
| **md** | **40px** | **`h-10`** | **`rounded-lg`** | **デフォルト** |
| lg | 44px | `h-11` | `rounded-lg` | アイコン付きボタン、余裕が欲しい時 |

デフォルトは全コンポーネント共通で **md (40px)**。

## 検討の経緯

### shadcn の 40px は日本語に最適か？

shadcn/ui のデフォルト高さ 40px は英語基準。日本語は漢字・ひらがなの字面が大きく（正方形に近い）、同じフォントサイズでも視覚的密度が高い。そのため上下の余白が英語より窮屈に感じる。

### 比較検討

カタログページで 36px / 40px / 44px / 48px の 4 段階を Button・Input・Select で並べて目視比較した。

- **36px**: コンパクトすぎ。日本語メインでは窮屈
- **40px**: テキストのみなら十分。英語基準だが許容範囲
- **44px**: アイコン付きボタンで最適。Apple HIG のタッチターゲット (44px) にも合致
- **48px**: 大きすぎ。アプリっぽさが薄れる

### デフォルト値のジレンマ

44px が日本語に最適だが、以下の理由でデフォルト md = 40px を維持：

1. **テキストのみのボタンは 40px で十分** — アイコンがなければ密度が低く、40px で窮屈に見えない
2. **コンポーネント間のデフォルト統一** — Input/Select を 44px デフォルト、Button を 40px デフォルトにすると、フォームで横並びにした時にデフォルトで高さが揃わない。これは気持ち悪い
3. **44px は lg で明示的に指定可能** — 必要な時に `size="lg"` で使える

「日本語に最適化」の思想は、44px という選択肢を用意していること自体で満たされる。

### 今後の変更可能性

実際にアプリを作る中で「md = 40px だと不足」と感じたら、md = 44px への変更を検討する。YAGNI に基づき、現時点では統一デフォルトを優先する。
